# AutoCLiKD

Android 向けのオープンソース自動連打アプリです。選んだアプリが前面にあるとき、画面上の小さな操作メニューからタップを開始・停止できます。

## 機能

- インストール済みの起動可能アプリから対象を選択
- 対象アプリ起動時にフローティングメニューを表示
- 対象アプリから離れたときにメニューを隠す（初期設定で有効）
- 画面上でタップ位置を指定
- 50 ms から 5,000 ms までの連打間隔
- 任意で間隔を ±15% ランダム化
- AMOLED ブラック、ライト、端末設定に合わせるテーマ

## 初回設定

1. AutoCLiKD を開き、対象アプリを選びます。
2. 「重ね表示を許可」から他のアプリの上に表示する許可を与えます。
3. 「ユーザー補助サービスを有効化」から AutoCLiKD を有効にします。タップ実行と前面アプリの検出に必要です。
4. タップ位置を選び、間隔などを設定します。
5. 対象アプリを開き、表示されたメニューから「連打開始」を押します。

アプリを更新した後、前面検知の動作が変わらない場合は、Android のユーザー補助設定で AutoCLiKD を一度オフにしてから再度オンにしてください。

ユーザー補助サービスは前面アプリの識別にアクティブなウィンドウ情報を参照し、画面上のタップを実行します。画面内の文章や入力文字は読み取りません。間隔のランダム化は機械的な周期を変えるだけで、アプリ側の検知を確実に防ぐ機能ではありません。

アプリ一覧表示のため `QUERY_ALL_PACKAGES` を使います。Google Play 配布を行う場合は、同権限に関する Play のポリシー確認が必要です。

## ビルド

JDK 17 と Android SDK 36 を使います。初回は Android Gradle Plugin 8.10.1 の取得が必要な場合があります。

```sh
JAVA_HOME=/path/to/jdk-17 \
GRADLE_USER_HOME=/path/to/gradle-cache \
./gradlew assembleDebug
```

APK は `app/build/outputs/apk/debug/app-debug.apk` に生成されます。`local.properties` は各環境の SDK パスに合わせて設定してください。
